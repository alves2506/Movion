Movion — Gerenciamento e Manutenção Automotiva

> Aplicativo desenvolvido em React Native com Expo para auxiliar motoristas no controle de manutenções preventivas, histórico de serviços e acompanhamento de peças e pneus de seus automóveis.

---

## Sobre o Projeto
O Movion nasceu da necessidade de simplificar a vida de motoristas particulares e profissionais que buscam manter o histórico de manutenção de seus veículos organizado. Com uma interface intuitiva e persistência local, o app ajuda a evitar gastos imprevistos e garante mais segurança no trânsito através do controle rigoroso de quilometragem, trocas de óleo, filtros, freios e pneus.

---

## Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias e ferramentas:
* React Native (com Expo) — Framework para desenvolvimento mobile multiplataforma.
* React Navigation — Gerenciamento de rotas e navegação entre telas (`Native Stack`).
* JavaScript (ES6+)** — Linguagem principal de programação.
* AsyncStorage / Armazenamento Local** — Persistência dos dados de veículos e manutenções no dispositivo.

---

 Principais Funcionalidades (Checkpoints Atuais)
* Cadastro de Veículos: Registro de marca, modelo, ano, placa e quilometragem atual do automóvel.
* Histórico de Manutenções: Listagem cronológica dos serviços realizados (trocas de óleo, reparos, etc.).
* Navegação Fluida: Transição dinâmica entre a tela inicial (Dashboard), gerenciamento de veículos e histórico de manutenções.
* **Validação de Formulários:** Alertas inteligentes para garantir que nenhum dado obrigatório fique em branco.
